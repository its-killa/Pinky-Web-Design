Graphic Design Project

About This Project

Project ini adalah eksplorasi desain grafis dengan tema "Self Love". Dibuat menggunakan kombinasi tipografi 3D dan palet warna pink estetik untuk menyampaikan pesan positif yang hangat kepada semua orang.

Tools Used 🛠️

  • Photoshop
  • Illustrator
  • Figma

Challenge: Menyeimbangkan elemen visual yang ramai agar tetap terbaca jelas tanpa mengurangi nilai estetikanya.
