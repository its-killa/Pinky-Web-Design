## 📖 About The Project
This project is an exploration of **Aesthetic UI/UX Design** combined with technical coding skills. The goal was to move away from boring, rigid layouts and create something dynamic, interactive, and visually pleasing.

### ✨ Key Features:
* **🖼️ Interactive Image Slider : ** Built with vanilla JavaScript logic.
* **📱 Fully Responsive : ** Looks good on laptops and mobile phones.
* **💫 Smooth Animations : ** CSS floating effects, hover transitions, and bouncy elements.
* **🎨 Glassmorphism & Pastel UI : ** Modern design trends with a cute twist.
* **🛍️ Pricing Cards : ** Custom layout using Flexbox.

## 🚀 How to Use (Manual Way)
Want to build this website yourself from scratch? Follow these steps to "Save & Run" manually!

### 1. Create the Folder
* Create a new folder on your laptop/computer.
* Name it: `My-Cute-Website`.

### 2. Create the Files 📝
You need to create 3 main files inside that folder.

#### A. HTML File
1. Open Notepad (or VS Code).
2. Copy the code from `index.html` in this repository.
3. Paste it into your Notepad.
4. **Save As** -> Name it: `index.html`.

#### B. CSS File
1. Create a new file again.
2. Copy the code from `style.css`.
3. Paste it.
4. **Save As** -> Name it: `style.css`.

#### C. JavaScript File
1. Create a new file.
2. Copy the code from `script.js`.
3. Paste it.
4. **Save As** -> Name it: `script.js`.

### 3. Save the Images 🖼️
The website needs images to look cute!
1. Right-click on the images in this repository (e.g., `chica.jpg`).
2. Choose **"Save Image As..."**.
3. Save them inside your `My-Cute-Website` folder.
4. **Important:** Make sure the file names match the code (e.g., `chica.jpg`, not `image(1).jpg`).

### 4. Run It! 🏃‍♀️
* Go to your folder.
* Double click `index.html`.
* Enjoy your cute website! ✨
